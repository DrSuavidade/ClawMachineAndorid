# Claw Machine UI & Cabinet Style Bible (10-Machine Roster)

## 1. System Vision & Architecture

Every machine in the 10-cabinet roster transforms the player's physical and visual fantasy while keeping the underlying UX 100% constant and intuitive.

### 3-Layer Design Law
1. **Fixed UX Skeleton (Invariable)**:
   - Identical anchor positions, touch hitboxes, button sizes, modal containers, 7-day streak card grid, 3-row quest list, and 3x3 collection grid.
2. **Cabinet Theme ("CSS Skin")**:
   - Palette (`primary`, `secondary`, `accent`, `surface`), marquee frame borders, button textures, lighting tints, claw aesthetic, and chute styling.
3. **Global Game Identity (Unbroken)**:
   - Coin currency (`🪙`), gem currency (`💎`), rarity badges (Normal: Slate Blue `#4A90E2`, Rare: Amethyst Purple `#9013FE`, Secret: Radiant Gold `#F5A623`), standard action verbs (Claim/Confirm = Green/Gold, Close/Cancel = Neutral/Red).

## 4. UI Implementation Standards

1. **Sprite Slicing**:
   - Frames and borders must use standard 9-slice borders with 8px–16px safe corners so elements scale seamlessly across all Android aspect ratios (16:9 up to 21:9).
2. **Readability Rules**:
   - All text must exceed contrast ratio `4.5:1` against its immediate surface backing.
   - Text colors (`headerText` / `bodyText`) are explicitly defined per theme to prevent dark-on-dark or washed-out text.
3. **Audio-Tactile Parity**:
   - Each cabinet theme maps to distinct button click and win fanfare tones (e.g. vintage bell chime for Circus, coin drop for Arcade, mechanical click for Steampunk).
